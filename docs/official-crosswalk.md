## 0. 结论摘要

1. 名称与英文名有官方原文依据；动画使用「国家电网有限公司 / State Grid Corporation of China」，未使用 2017 年前的旧名。
2. 标识图形等比缩放、未改色、未加特效、未拆分；因官方矢量源文件与 VI 手册未公开，净空采用行业保守值，正式发布前需替换为官方组合文件。
3. 复诵挂 **GB 26860—2011 §7.3.1.2**，没有误挂到《电网调度管理条例》（该条例全文无「复诵」字样）。
4. 合闸挂 **GB 26860—2011 §7.3.6.1**（送电合闸与停电相反序）；并网前置在日志中体现《电网调度管理条例》§25/§26。
5. 规模数据全部锁定 2024 年口径，且区分了「经营区域」与「全国」；未使用任何停用口号。
6. 动画明确标注「非官方演示 / 非实时调度数据」，不冒充官方系统；地图标注 `SIMULATED`，非标准地图。

## 2. 明令避免的易错点（本次已核对）

| 易错点 | 事实 | 本片处理 |
|---|---|---|
| 把「复诵」归到《电网调度管理条例》 | 条例全文没有「复诵」「操作票」「工作票」「监护」字样 | 复诵只挂 GB 26860—2011 §7.3.1.2 |
| 引用 Q/GDW 1799.1 条款号 | 企业标准正文未公开，网传版本无法确认 | 不引用其条款号；需要制度依据时用 GB 26860 |
| 使用 2017 年前旧名「国家电网公司」 | 2017 年改制后为「国家电网有限公司」 | 全片名称文案只用现名；**标识环内的注册商标文字原样保留、不修改**，与名称文案分开处理 |
| 使用停用口号「诚信 责任 创新 奉献」「奉献清洁能源 建设和谐社会」 | 现行企业文化页未列，视为停用 | 未使用；只用现行宗旨 |

## 3. 「启动流程」与官方操作制度的映射

官方没有「启动动画流程」，但动画的四拍可以逐拍挂到有出处的操作制度上：

```
接入核验 ──→ 调度指令 ──→ 复诵 ──→ 执行 ──→ 并网前置 ──→ 合闸 ──→ 全网启动
   │            │          │        │          │            │          │
条例§11      条例§21     GB§7.3.1.2 条例§22  条例§25/§26  GB§7.3.6.1   艺术加工
持证上岗      按规定发令   复诵无误   必须执行  协议/统一调度  送电反序     无官方流程
```

- **有原文依据**：4 个环节（发令、复诵、并网前置、合闸顺序）+ 接入的制度含义（持证上岗）。
- **艺术加工**：介入方式（按住/拖动）、时间压缩（单把手代替逐项操作票）、全网扫描视觉、所有读数。
- **未覆盖**：操作票逐项打钩（GB §7.3.4/§7.3.6.2）、操作后检查（§7.3.6.8）、事故处置（599 号令）、五级调度层级图。这些属于「启动动画」之外的业务流程，未强行塞入。
