# 国家电网 × 终末地（ZMD）DSH 启动动画 · 设计说明

> 交付物：`dsh-boot-grid-zmd/`（DSH 插件 + 可直接打开的静态动画）
> 设计依据：`research/zmd-style.md`（终末地 token 提炼）、`research/state-grid-official.md`（国网官方文档调研）
> 对照记录：`docs/official-crosswalk.md` · 自检报告：`docs/acceptance.md`

---

## 1. 一句话概念

**把「开机」做成一次调度操作：** 屏幕是一台工业调度终端 SC-01。调度员按住接入、复诵调度指令、亲手把断路器推到「合」，然后看着电流自西向东点亮全国电网。

视觉语言取终末地的「石墨调度台」——1px 结构线、全直角、信号黄只出现在读数/进度/角标/危险带；国家电网的绿只承担一个语义：**认证通过、线路带电、系统正常**。两者不抢同一个元素，也不共享同一个强调色。

### 1.1 三项核心体验怎么落地

| 要求 | 具体做法 | 可验证据 |
|---|---|---|
| **互动感强** | 三种不同手感的真实交互：按住 1.2s（持续压力）→ 点击复诵/执行（决策）→ 拖动合闸（连续控制）；地图悬停有跟随读数；自动演示可被任何真实输入接管 | `tools/test.mjs`、`16-hover-node.png`、`10-hold-success.png`、`13-breaker-drag.png` |
| **线条简洁流畅** | 全片只有 1 / 2 / 6px 三档线宽；省界是单色 1px 线稿；扫描用 clip 揭示而不是叠多层描边；动画只动线长、位置与透明度 | `05-boot.png`、`boot.css` 线宽 token |
| **极具艺术感** | 超大 `SC–01` 与留白对位、地图自西向东的「点亮」、收尾 420ms 全屏黄扫、黄黑危险带与画框角标构成的工业版式 | `01-access.png`、`05-boot.png`、`17-sweep.png` |
| **反馈清晰可感知** | 每个交互都有「进行中 / 成功 / 失败」三态：进度环 + 计时、电压数字、边框转绿、红框抖动、提示条、日志、提示音；下一步自动聚焦 | `docs/acceptance.md §4` |

## 2. 范围与不做什么

做：
- 一段约 16 秒（自动演示）的启动序列，四拍：接入核验 → 调度指令 → 合闸并网 → 全网启动。
- 三种可实际触发的交互（按住 / 复诵点击 / 拖动合闸）+ 地图悬停。
- 可直接在浏览器打开的静态版；以及按 DSH 启动插件规范封装、开机时全屏播放的版本。

不做（资料未支持，或超出「启动动画」范围）：
- 不新增品牌元素、业务系统入口、真实调度数据接口、账号体系。
- 不实现官方 VI 手册中未公开的完整标识使用细则；只做保守处理并在对照表标注不确定性。
- 不做移动端竖屏专属版式（低于 1080px 宽有降级，但不是本次验收目标）。

## 3. 视觉系统

### 3.1 色板（角色先行，占比受控）

| token | 值 | 角色 | 占比 |
|---|---|---|---|
| `--bg` | `#0f1419` | 石墨舞台 | 55–70% |
| `--bg2` | `#131a21` | 面板/次级层 | 10–20% |
| `--paper` | `#f1eee5` | 官方标识白牌、完成页铭牌 | <3% |
| `--ink` | `#eceded` | 主文字 | 6–12% |
| `--dim` / `--faint` / `--line` | 白 40% / 16% / 12% | 元数据 / 次级线 / 结构线 | 结构量 |
| `--acid` | `#fbfb46` | 信号黄：进度、主读数、角标、危险带 | **2–6%** |
| `--volt` | `#37d6ae` | 屏幕发光绿：带电、成功、认证 | <2% |
| `--volt-deep` | `#006569` | 公开说法中的国网绿屏幕值（二手，仅作深色底参照） | 点状 |
| `--alert` | `#ff3b30` | 中断/未到位 | <1% |

用色纪律：
- **黄不做底色填充**（唯一例外是收尾 420ms 的全屏扫屏，转场用，见 §5.4）。
- **绿只占一个语义槽**：认证、带电、正常。同一元素不同时用黄和绿。
- 青蓝不属于终末地（那是方舟官网的信号色），本片不使用青蓝泛光；地图带电色取国网绿的暗底高亮派生，而非另起一套品牌色。
- 危险条纹保持黄黑，不换红绿。

### 3.2 字体与排版

| 角色 | 字体栈 | 用法 |
|---|---|---|
| 等宽/读数 | Bahnschrift → Cascadia Mono → Consolas | 终端号、百分比、电压/频率、日志、标签；`tabular-nums` |
| 中文 | Noto Sans SC → Microsoft YaHei | 标题、步骤名、指令正文 |
| 压缩展示 | Bahnschrift（大字重） | 仅 `SC–01` 一个拉丁字标位 |

规则：
- 拉丁全大写、小字号大间距（8–10px / .18–.42em），大数字字距归零。
- **中文不进「超大拉丁字标」的位置**：主视觉字标是终端编号 `SC–01`，中文以 22px/800/.3em 的标注行出现。这是终末地样片里「中文永远是被大写包围的少数派」的直接沿用。
- 全片无圆角（状态点、进度环除外）、无斜切、无投影卡片。

### 3.3 线条与几何

- 线宽只有三档：**1px**（结构线/网格/省界/读数）、**2px**（12px L 形四角）、**6px**（上下危险带）。
- 画框内缩 `clamp(30px, 4vw, 58px)`；内容 5.2vw；顶部/底部 metabar 在画框之外。
- 背景双层网格 64px / 16px，径向 mask 渐隐；扫描线纹理 1px/3px 白 2.5%。
- 左侧 14px 竖轨是唯一的大面积黄色：黄填充 + 41px 黑刻痕，直接对应进度。
- 地图：省界 1px 白 20%，经纬参考线 4.5%，城市光点烘焙成「灰底 + 绿色热点」两层，随扫描前沿裁剪揭示；特高压走廊按二次曲线采样，灰底稿贴地、通电后整条抬高 6px 转绿，电流脉冲沿同一弧长运行。
- 地图不是透视倾斜的 3D 模型：它是一块有 9–15px 石墨侧壁的实体板，地面参考线提供伪透视，国土几何、经纬和相对位置保持准确。

#### 深度与遮挡顺序

| 层 | 处理 |
|---|---|
| 背景 | 石墨底 + 低透明度等高线/网格 + 左侧与边缘暗角；扫描带只在地图层（z7），颗粒只压背景（z4） |
| 地图 | 透视地面参考线 → 石墨侧壁 → 烘焙地表/省界；浅底座与 1px 顶光让地图成为独立结构面 |
| 数据 | 城市灰点贴地；绿色热点随带电淡入；线路灰底稿贴地，绿线抬起；节点有投影、侧面、顶面 |
| 面板 | 交互坞不透明石墨面 + 上缘亮线 + 4px 底座阴影；坞内凹槽把控件与面板分开 |
| 控件 | 按钮/把手 1px 顶光 + 3px 暗侧边；按下压低 1px；合闸轨道为 12px 内凹槽 |
| 提示 | 操作提示 10px / 65% 白；站名深底 + 避让 + 引线；tooltip 在地图之上且钳制边界 |

品牌与文字层（z14–z22）高于扫描/颗粒，官方标识与操作面不再被全屏效果覆盖。

## 4. 交互设计（四拍）

### 4.1 按住接入（ACCESS）
- 控件：58px 高直角按钮，左侧圆环进度 + 右侧 `0.00s` 计时；按住 1.2 秒完成。
- 反馈：
  - 进行中：圆环 `stroke-dashoffset` 连续收拢、按钮内部淡黄填充、计时递增、低频 50/100Hz 嗡鸣随进度加强。
  - 成功：边框转绿、短促三音上行、提示条 `接入成功 · 权限等级 3`、日志 `身份核验通过`、总进度推进到 12%。
  - 中断：红框 + 300ms 横向抖动 + `已中断 · 需持续按住 1.2 秒` + 日志 `接入中断 · 时长不足`。
- 键盘：聚焦按钮后按住 Space/Enter；`pointerleave` 也会中断，避免误触。

### 4.2 调度指令与复诵（ORDER）
- 指令逐字打出（26ms/字）：`1000kV 淮南—上海 特高压线路 由检修转运行`。
- 「复诵」点击后，回显行以绿色逐字打出（18ms/字），完成后「执行」才可用并自动获得焦点。
- 反馈：按钮按下态只改边框色（不放大、不填色）、成功音、绿色回显、`复诵一致 · 校验通过`、日志。
- 制度依据：复诵挂 **GB 26860—2011 §7.3.1.2**，不挂《电网调度管理条例》（后者全文无「复诵」字样，见对照记录）。

### 4.3 合闸并网（BREAKER CLOSE）
- 控件：水平轨道 + 可拖动把手（`role="slider"`，方向键/Home/End 可用）。
- 反馈：
  - 拖动中：黄色填充跟随把手、电压读数 `0.0 → 525.0 kV` 实时爬升、嗡鸣随开度加强、轨道刻痕保持不动（重量来自跟随，不是回弹）。
  - 未到位松手（<90%）：320ms 弹簧回零 + `把手未到位 · 已复归` + 日志。
  - 到位：把手转绿、`525.0 kV`、低频撞击声、日志 `断路器合位 · 线路电压建立`。
- 制度依据：送电合闸顺序 **GB 26860—2011 §7.3.6.1**；并网前置在日志里写「并网协议已签 / 调度许可已下达」（**《电网调度管理条例》§25、§26**）。

### 4.4 全网启动与收尾（BOOT → DONE）
- 6.4 秒分段扫描（0→30→32→62→64→90→92→100，段间停顿），自西向东揭示地图与城市光点。
- 同步：电压 0→525 kV、频率 49.62→50.00 Hz、有功 0→2.41 GW（全部标注 `SIM`，非实时数据）。
- 收尾：全屏黄扫 420ms（`cubic-bezier(.76,0,.24,1)`）→ 黑场 → 完成页（官方标识白牌 + `系统已启动` + 企业宗旨 + 2024 年公开数据 + 进入按钮）。
- 完成页点击：iframe 内向宿主发 `boot-grid-zmd:done`；独立打开则重播。覆盖层内 3 秒无人操作会自动交还，避免把应用扣在完成页。

### 4.5 附加互动
- 地图节点悬停：右上角经纬读数实时跟随，节点出现张开的角括号 + 深色 tooltip（站名 / 电压等级），点击给出「示意节点」提示。
- 播放模式：底部「模式 手动 / 模式 自动」切换。**默认手动**，适合自己点完四拍；切到自动后第一拍 1.1s 自动按住，后续自动复诵/执行/合闸。选择写入 cookie（`dsh_boot_grid_zmd_mode`），下次启动保持；自动播放中任何真实指针或按键输入会立即转为手动并记住该选择。
- 启动覆盖层由 `screen.js` 读取同一 cookie 决定 iframe 的 `?auto=0/1`；cookie 不受 DSH 端口变化影响，清空浏览器 cookie 后回到默认手动。

### 4.6 可访问性与降级
- 全部控件是原生 `<button>`；合闸把手有 `role="slider"` 与 `aria-valuenow`。
- 焦点环 2px 实线 + 2px offset；Esc 跳过；完成页 Enter/Space 进入；完成页打开时背景层设 `inert`，Tab 只落在完成页。
- 模式切换是原生 `<button>`，带 `aria-label` 与 `title`；手动/自动状态同时显示在顶部 metabar。
- `prefers-reduced-motion: reduce`：关闭扫描带/入场位移/黄扫，保留状态与交互。
- 无 WebGL、无外部字体、无网络请求；音频在第一次真实输入后才启用，可一键关闭。

## 5. 动效编排

| 时间 | 事件 | 参数 |
|---|---|---|
| 0.00s | 画框 / 危险带 / 四角 | 危险带 600ms `cubic-bezier(.6,0,.2,1)`，角标 400ms 淡入 |
| 0.25s | kicker | 550ms 上移 6px |
| 0.45s | `SC–01` | 550ms 上移 18px + 8px 模糊到清晰 |
| 0.72s | 中文标题 | 700ms 上移 8px |
| 1.00s | 副标题 / 分隔线 | 线 900ms scaleX |
| 1.15s | 遥测 / 日志 | 500ms 淡入，日志 150ms/条 |
| 用户 | 接入 | 按住 1.2s；总进度 0→12% |
| +0.7s | 指令 | 26ms/字；复诵完成前「执行」禁用 |
| +0.8s | 合闸 | 拖动；≥90% 关闭；总进度 52→72% |
| 6.4s | 全网扫描 | 分段缓动；日志按 p 阈值插入 |
| 6.4s | 收尾 | 黄扫 420ms → 黑场 500ms → 完成页 600ms 淡入 |

阶段切换不再整屏平移/放大：机架和文字固定，只有当前面板内容从坞内凹槽以 `clip-path` 揭示。减弱动效下取消扫描/位移/黄扫，保留状态、读数和交互进度。

缓动只用三条：
- 线/条：`cubic-bezier(.6,0,.2,1)`
- 逐字/标题：`cubic-bezier(.2,.9,.2,1)`
- 收尾扫屏：`cubic-bezier(.76,0,.24,1)`

数字滚动不做补间动画，直接写 `textContent` + `tabular-nums`（终末地样片的做法）；只有百分比与电压这类连续量按帧更新。

## 6. 与 ZMD 风格的逐项对照

| 终末地特征（research/zmd-style.md） | 本片实现 |
|---|---|
| 石墨底 + 纸面双表面，共用一套骨架 | 主舞台石墨；官方标识与完成页铭牌用纸面白牌 |
| 信号黄只占 2–6%，只做读数/进度/角标/危险带 | 黄只在：竖轨、百分比、步骤号、危险带、扫描线、角标、提示焦点 |
| 全直角，无切角、无圆角卡片 | 全部控件直角；仅状态点与进度环为圆 |
| 线宽 1/2/6px 三档 | 结构 1px、L 角 2px、危险带 6px；无更粗描边 |
| 58px 内缩画框 + 12px L 角 + 26px metabar | 画框 `clamp(30px,4vw,58px)`、12px 角、metabar 26px |
| 14px 竖轨 + 41px 刻痕 + 顶端读数 | 14px 竖轨 + 41px 刻痕；读数放在左栏底部（为避免与标题抢位） |
| 中文不进超大拉丁字标位 | 大字标是 `SC–01`；中文是 22px 标注行 |
| 逐字 18px 上移 + 8px 模糊、45ms 错峰 | `SC–01` 整块做同样的模糊上移；日志逐条 150ms |
| 单次全屏黄扫收尾（420ms） | 完成时一次 420ms 黄扫 → 黑场 → 完成页 |
| 不用青蓝泛光；不用 glitch 抖动 | 绿只做「带电/正常」；中断只抖 300ms 一次 |
| 按钮：平直表面 + 1px 边，hover 只改前景/边色 | 保留直角与细边；用 1px 顶光/3px 暗侧边建立「可按」厚度，hover 仍只改前景/边色，按下压低 1px |
| 不用浮动卡片/大投影 | 交互坞与控件只有 1–4px 的结构边和短接触阴影，没有悬浮卡片、圆角或大面积发光 |

## 7. 官方文档约束的落地

| 约束 | 落地 |
|---|---|
| 法定名称「国家电网有限公司」 | 顶部 metabar 左端全称；英文 `STATE GRID CORPORATION OF CHINA` 紧随 |
| 标识不改色、不变形、不拆分、不加特效、深底用白底保证对比 | 标识以等比 48px 放在纸面白牌上；不加滤镜/动画/扫光；与文字保持 12px 净空 |
| 国网绿只作「认证/正常」 | 绿只出现在授权、合闸、带电、完成页；官方绿 `#006569` 仅在文档与深色参照中出现 |
| 调度指令、并网、复诵、合闸有依据 | 见 §4 与 `docs/official-crosswalk.md` 的逐条对照 |
| 不编造过时口号 | 只用现行「人民电业为人民」；不用「诚信 责任 创新 奉献」等停用表述 |
| 公开数据带年份 | 完成页写「经营区域覆盖 26 个省（自治区、直辖市）· 供电范围占国土面积 88% · 供电人口超 11 亿（2024）」 |
| 不冒充官方系统 / 不展示真实调度数据 | 顶部 `SIM`、底部「非官方演示 · 非实时调度数据」、完成页脚注「标识归权利人所有」；地图标注 `SIMULATED`；终端号与调度员编号为虚构 |

```
├─ smoke.mjs          离线冒烟测试
├─ tools/             截图 / 交互测试 / 子路径服务
└─ docs/              设计说明、官方对照、自检报告、截图
```

- **单文件静态动画**：`assets/index.html` 直接双击可运行，`?auto=1` 自动演示，`?jump=access|order|close|boot|done` 调试定位。
- **DSH 插件**：`entry.js` 以白名单方式在 `/plugins/dsh-boot-grid-zmd` 下提供 6 个文件；`screen.js` 注入全屏 iframe。动画在 iframe 内，不污染宿主样式。
- **退场兜底**：iframe 内 `boot-grid-zmd:done/skip`、外层 Esc、9s 载入看门狗、60s 总时长上限；任意一条命中即移除覆盖层。
- **渲染与深度**：新增 `#mapGround` 存放透视地面、石墨侧壁和烘焙地表/省界；城市点烘焙成灰底 + 绿色热点两层，逐帧只做一次 `clip + drawImage`；7 条走廊按二次曲线采样并缓存弧长，脉冲与线芯共用几何；DPR 上限 2，无第三方依赖。

## 9. 运行方式

```bash
# 1) 直接看
start dsh-boot-grid-zmd/assets/index.html

# 2) 自动演示（与 DSH 开机一致）
start "dsh-boot-grid-zmd/assets/index.html?auto=1"

# 3) 用插件真实路由起本地服务
node dsh-boot-grid-zmd/tools/serve.mjs 8123
# http://127.0.0.1:8123/plugins/dsh-boot-grid-zmd/

# 4) 装进 DSH（会与现有启动屏插件互斥，二选一）
dsh plugin add link:E:/dshwork/dsh-boot-grid-zmd
```
