# 空间层次与立体感优化记录

> 基线：`c717a74`（已在当前 profile 启用的版本） · 优化后：工作区版本（四阶段交互与 DSH 集成未改）
> 对比方法：已安装路由 `http://127.0.0.1:50130/plugins/dsh-boot-grid-zmd/`，同一组 1440×900、同一扫描/合闸进度截图；不使用不同进度冒充改善。

| 级别 | 问题 | 证据 | 预期效果 |

## 2. 五层结构

| 层 | 实现 |
|---|---|
| 背景 | 石墨底、降低密度的等高线与网格；`#bg` 透明度 .48、网格 .55；左侧/边缘暗角把注意力推向地图 |
| 地图 | 新增 `#mapGround`：透视地面参考线 → 12px 左右石墨侧壁 → 烘焙地表/省界；国土几何不旋转、不伪造地形 |
| 数据 | 城市点烘焙成两层（灰底 + 绿色热点）；线路灰底稿贴地，通电后整条抬高 6px 并转绿；脉冲沿共享弧长运行 |
| 结构面板 | 交互坞不透明石墨面、上缘亮线、4px 底边和短接触阴影；坞内凹槽把控件与面板分开 |
| 交互主体 | 按钮/把手有 1px 顶缘高光 + 3px 暗侧边；按下压低 1px，轨道为 12px 内凹槽；成功只转绿 |
| 提示 | 底部操作提示 10px / 65% 白；站名有深底、避让和引线；tooltip 抬到地图之上并钳制在边界内 |

## 3. 代码落点

- `assets/index.html`：新增 `#mapGround` 画布（地面/侧壁/地表），`#map` 只保留动态层。
- `assets/boot.css`
  - `.scan` 降到 z7（地图之上、框架/文字/交互坞之下），`.grain` 降到 z4；官方白牌与操作面不再被覆盖。
  - `#bg` 透明度、网格透明度、`#stage::before` 左/边缘暗角。
  - `.mapwrap::before` 地图浅底座；`#mapGround` 层级；地图角标文字加实体底。
  - `.dock` 不透明面 + 上亮/下暗边 + 4px 底座阴影；`.dock-body::before` 内凹槽。
  - `.hold` / `.key` 表面、1px 顶光、3px 暗侧边、按压 1px；`.brk-track::before` 凹槽；`.brk-knob` 凸起 + 把手 10px 标签；`.boot-bar` 内凹 + 渐变发光条。
  - `.panelIn` 改为裁切揭示；删除 `#stage.punch`；`prefers-reduced-motion` 关闭扫描、位移和过渡。
- `assets/boot.js`
  - `buildMap`：地面网格、侧壁挤出、地表/省界烘焙；`dotsCanvas` / `hotDotsCanvas`；线路按二次曲线采样并计算弧长。
  - `pathPointAt`：按弧长取点，与 `drawCorridor` 同一几何。
  - `drawMap`：灰线路底稿贴地；通电后数据层抬 6px；城市点一次裁剪 drawImage；节点投影/侧面/顶面/标签避让；扫描线只在数据层。
  - `onMapMove`：按节点顶面高度命中；tooltip 边界钳制。
  - `loop`：减弱动效下仅在状态变化时重绘；断路器拖动取消回弹并加 dragging 状态。

对比要点：

1. **接入态**：旧版省界/线路几乎同灰度；新版地图是浅底座上的实体板，省界成为细线，节点有短柱和顶面。
2. **合闸态**：旧版把手像轨道上的小标记；新版轨道内凹、把手凸起，按住/拖动有 1px 压低与侧影变化。
3. **启动态**：旧版黄底绿芯并置、点云和站名抢读；新版整条线路转绿、抬离线面，站名有深底和引线，城市热点只随通电亮起。
4. **构图**：旧版背景装饰直接压过官方白牌与坞；新版扫描/颗粒退到地图和背景层，文字与操作面保持稳定。

## 6. 取舍与未做

- **没有**做透视倾斜、整图 bloom、厚重双描边、每个面板亮边或每个城市点发光；深度来自一致的浅底座、上亮下暗、遮挡顺序和一次性通电抬升。
- **没有**改官方标识、白牌比例/颜色/净空；没有新增品牌素材、地图数据、依赖或业务模块。
- 地图仍为示意数据、非标准地图；官方 VI/色卡/矢量标识仍不可得，相关限制沿用 `docs/design.md` 与 `docs/official-crosswalk.md`。
- 未录屏验证「刷新 DSH 首页后 iframe 覆盖层实际铺开」；覆盖层本身已用 `screen.js` 注入 + 自动四阶段交还验证，且当前 profile 的实机路由已跑通。
- 未做真实 GPU/不同 DPI 的帧率基准；16.7ms 只代表本机 headless Edge 的一次采样。
- tooltip 边界钳制在 1440 下验证；其他尺寸只验证了节点命中，未逐尺寸目视检查 tooltip/toast。
